# Actualizaciones webs

Actúa como un diseñador UI/UX Senior experto en conversiones (CRO) y desarrollador Full-Stack. Necesito construir una landing page de alto valor para mi agencia. Somos una agencia que actualiza y transforma páginas web obsoletas en máquinas de venta.

1. Diseño Visual: Estilo 'Dark Mode' tecnológico de alto contraste (fondos negros profundos, acentos en neón cian o violeta eléctrico). Tipografía moderna, tipo 'Inter' o 'Geist'. Diseño ultra limpio, con mucho espacio en blanco (espacio negativo) para facilitar la lectura.

2. Estructura CRO (Orden estricto de arriba hacia abajo):

Hero Section:Título grande e impacto directo: 'Transformamos tu presencia digital en 48 horas'. Subtítulo: 'Estrategia de conversión, velocidad extrema y tecnología de vanguardia'. Botón CTA principal brillante con efecto de resplandor: 'Quiero mi Landing en 48hs'.

Sección de Métricas de Autoridad:Un grid de 3 columnas con números grandes y animados que suben progresivamente al hacer scroll (ej: '+200% Conversión', '48hs de Entrega', '100% Optimizado').

Sección de Agitación (Carrusel):Un slider o grid comparativo estilo 'Antes y Después' mostrando cómo una web aburrida se transforma en un diseño premium.

Sección Interactiva (Calculadora):Una calculadora simple e interactiva de 'Impacto de Conversión' donde el usuario deslice una barra horizontal para ver cómo aumentarían sus ingresos con una web optimizada.

Cierre (Segundo CTA):Una frase final contundente y un botón grande centrado que repita el llamado a la acción principal.

3. Interactividad y UX: Incluye animaciones fluidas al hacer scroll usando Framer Motion. Los botones deben tener efectos 'hover' magnéticos y transiciones suaves. La página debe sentirse viva, con micro-interacciones sutiles pero profesionales.

4. Stack Técnico Requerido: Usa React + Tailwind CSS. Optimiza todos los componentes para carga instantánea. Asegúrate de que el código sea limpio, modular y esté completamente listo para ser exportado y desplegado en Vercel sin errores.
